Miško Ritmu

Company website for Miško Ritmu, a Lithuanian forest management (miškotvarka) and forestry consulting company. Built as a solo project with Next.js and TypeScript.

About the site

The site presents the company's forestry services — forest management planning, tree-cutting permits, forest boundary marking, timber volume assessment, and consulting — along with a short company history and contact details. A secondary page offers a curated list of external forestry resources for clients.

Tech Stack
Next.js (App Router) + TypeScript
React
Plain CSS — no UI framework, including fully custom responsive breakpoints
next/image for optimized image loading
Deployed on Vercel
Pages
Route	Description
/	Home — hero, services grid, about, contact
/helpful-links	Curated external forestry resources for clients
Features
Responsive design with dedicated breakpoints for tablet (≤992px), mobile (≤768px), and small phones (≤480px)
Service and resource cards collapse into a single column on mobile
Indexed on Google via Search Console with a submitted sitemap
